# Project Planning, Scheduling & Controlling

## Overview

End-to-end project planning and controlling for IT initiatives, from
Work Breakdown Structure definition through milestone tracking, with
quantified cost-saving outcomes. Includes hands-on deployment of self-
hosted project-management platforms for restricted LAN-only access.

## Technologies & tools

- **OpenProject** — self-hosted, Docker-deployed inside a VM for LAN-
  restricted user access
- **Notion**, **Trello**, **Obsidian** — project management and knowledge
  organization platforms
- Gantt charting and WBS tooling
- Kanban systems for delivery tracking

## Responsibilities & operational scope

- Project planning, scheduling, and controlling for IT initiatives
- Definition of project scope, deliverables, and milestones via detailed
  Work Breakdown Structure (WBS) and Gantt chart creation
- Decomposition of complex IT initiatives into actionable, trackable work
  packages aligned with technical and business objectives
- Establishment of project timelines and phase sequencing based on
  dependency mapping
- Identification and implementation of IT workflow improvements with
  tangible cost savings: reduced server energy consumption, optimized
  ISP contracts, software license consolidation, automation of recurring
  tasks, pay-per-use efficiency in hybrid infrastructures
- Self-hosted OpenProject deployment via Docker inside a VM, served on
  LAN for restricted corporate users
- Workflow, Kanban, and documentation-structure design using Notion,
  Trello, and Obsidian, to improve delivery efficiency and cross-team
  alignment
