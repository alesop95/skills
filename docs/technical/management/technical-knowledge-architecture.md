# Technical Knowledge Architecture & Documentation

## Overview

Strategic leadership of the corporate technical documentation function,
treating documentation as an industrial asset that captures system
architecture, configurations, and technical decisions both implemented
and planned. Includes design of node-based, hyperlinked knowledge
ecosystems unifying all core IT domains.

## Technologies & tools

- **ITGlue** — node-based IT documentation platform
- **Obsidian** — hyperlinked personal and team knowledge base
- **DokuWiki** — self-hosted wiki on Linux server
- Markdown-based documentation pipelines (see also DevOps and Workflow
  Automation)

## Responsibilities & operational scope

- Leadership of corporate technical documentation as a strategic
  industrial asset covering system architecture, configurations, and
  implemented/planned technical decisions
- Organization of files, folders, procedures, and performed activities,
  keeping the technical knowledge base continuously up to date
- Creation of a DokuWiki instance on a self-hosted Linux server
- Knowledge mapping and centralization through node-based documentation
  ecosystems (ITGlue, Obsidian) to build a hyperlinked, unified knowledge
  map across all core IT domains, with emphasis on the design process
- Documentation integrity, version control, and cross-referencing to
  support operational continuity, decision-making, and alignment with
  quality certification and cybersecurity frameworks
